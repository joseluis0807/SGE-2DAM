# 🏢 Tarea 1: La gestión empresarial - Caso 17

**Módulo:** Sistemas de Gestión Empresarial (SGE) - 2º DAM  
**Alumno:** Jose Luis  
**Caso analizado:** Caso 17 — Cadena de restaurantes "El Fogón Casero"

## 📄 Descripción del repositorio
Este repositorio contiene la entrega correspondiente a la primera tarea de evaluación del módulo de SGE. El documento principal incluye un análisis exhaustivo sobre los problemas de gestión e infraestructura tecnológica de una cadena regional de cinco restaurantes ("El Fogón Casero"), proponiendo soluciones reales basadas en los estándares del software empresarial moderno.

## 🛠️ Conceptos aplicados en el análisis
En el documento en PDF adjunto en este repositorio (`La gestión empresarial.pdf`), se han desarrollado los siguientes puntos clave del temario:

1. **Organización departamental:** Reestructuración de la plantilla de 45 empleados en departamentos funcionales (Dirección, Compras, Administración y Ventas).
2. **Diagnóstico y Causa Raíz:** Identificación de las "islas de información" que sufre la empresa al no contar con una base de datos centralizada.
3. **Implantación de ERP y CRM:** 
   * Justificación del uso de un **ERP** para centralizar el *Back Office* (compras unificadas y logística).
   * Justificación del uso de un **CRM** para el *Front Office* (fidelización de clientes y análisis de platos más vendidos).
4. **Arquitectura SOA:** Propuesta de migración desde un modelo tradicional Cliente-Servidor hacia una Arquitectura Orientada a Servicios (SOA) para poder integrar las comandas de las apps de reparto (Glovo, UberEats, etc.) directamente en la cocina mediante servicios web.
5. **Flujos E-Business:** Identificación de las comunicaciones **B2B** (proveedores y apps de reparto), **B2C** (clientes finales) y **B2E** (comunicación interna de empleados y camareros).
